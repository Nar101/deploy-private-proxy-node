# 安全与验收基线

## 凭证分级

绝不进入 Git、知识文档或对话：

- SSH 私钥、密码、验证码；
- UUID、Reality 私钥、short ID；
- 3X-UI Token、面板登录信息；
- 完整 VLESS/订阅链接；
- 含上述内容的数据库正文。

可记录但对外发布前脱敏：供应商、地区、实例规格、软件版本、公网 IP、公开端口、备份文件路径和哈希。

敏感文件本地权限使用 `600`。备份只报告路径和 SHA-256，不输出内容。

## 最小暴露面

- SSH：密钥登录；验证后禁 root 密码和普通密码登录。
- Reality：公网 TCP 443。
- 面板：不对公网开放，优先通过 SSH 隧道访问。
- 订阅：单节点默认不建公网订阅；确需时单独设计认证、TLS、更新与撤销机制。
- 临时诊断协议：完成定位后删除客户端、服务端入站和两层防火墙规则。

## 零断流与维护窗口

先使用本次已明确的网络边界。已有具体授权可复用，不重复询问。要求零断流时：

1. 变更前通过真实客户端记录出口 IP 和目标服务 HTTP 结果；
2. 用 `apt-get -s dist-upgrade` 模拟升级；命中 systemd、OpenSSH、Netplan、nftables、UFW 或内核时，不在当前连接上安装；
3. 只执行不触碰 443、Xray 进程和当前路由的动作，例如收紧敏感文件权限、为未使用端口增加明确拒绝规则；
4. 不重启 x-ui/Xray、SSH、服务器，不调整当前代理组；
5. 变更后核对服务 PID、监听端口、防火墙、原出口和用户选定 HTTP 目标；暂不测 Claude 时不发 Claude 请求。AlmaLinux 使用实际的 dnf/firewalld 或 nftables 状态，不照抄 Ubuntu 命令。

### 客户端重建前必须具备的恢复条件

默认使用只含新节点的测试组和少量域名。只有日志证明运行快照仍旧且热重载失败，才考虑重建；不能把缓存旧案例当成本次根因。

调用 `scripts/check-reload-safety.sh --evidence <json>` 检查本次证据，字段要求见脚本 `--help`。脚本只校验，不启动或停止网络。证据必须来自当前检查：

- 当前主节点、配置、出口和目标 HTTP 结果已保存；
- 新服务器精确 IP 走物理路径，旁路已验证；
- 备用代理来自独立进程，通过实际请求证明不依赖将被停止的隧道；
- 恢复动作能脱离 AI/SSH 会话执行，所需工具权限已验证，动作有确定的结束条件；
- 当前动作已有具体授权。

任一项缺失就不重建，继续读取日志或使用隔离客户端。不要把本次硬编码的临时恢复脚本复制成通用方案。恢复后核对 PID、监听、主节点、配置、原出口及 HTTP 请求；`Connected`、单一 `scutil` 输出或端口监听不能单独证明恢复。

### 服务端诊断窗口

`run-debug-window.sh` 在停正式服务前检查脱敏配置、依赖和 systemd 看门狗。等待 `READY` 后才发送测试请求；实时日志经脱敏刷新。退出或会话断开后，服务器本地动作终止整个调试进程组，等待正式服务 active 和预期进程监听原端口，并记录恢复结果。缺少这些条件时不能占用正式 443。

## 自动安全更新真相

`unattended-upgrades active` 只证明进程存在，不证明安全补丁来源已启用。至少同时检查：

```bash
apt-config dump | grep -E 'Unattended-Upgrade::(Allowed-Origins|Origins-Pattern)'
apt list --upgradable
apt-get -s dist-upgrade
```

确认当前 Ubuntu 版本对应的 `-security` 来源生效；不要把“服务 active”或“日志显示没有可升级包”单独当成安全更新完成。修正来源和安装补丁可能触发服务重载或要求重启，应放入用户允许的维护窗口。

## 公网端口探测

服务器内的 `ss` 只能证明进程监听，UFW 只能证明系统内层规则，二者都不能替代云厂商外层防火墙回读。开启 Shadowrocket/TUN 时，本机 `nc` 可能把所有目标端口都报告为可达；必须加入随机无监听端口作为阴性对照。对照也显示可达时，废弃整组结果，改从云控制台或不受代理接管的独立网络验证。

## 完成标准

全部成立后才能报告完成：

- 云实例 Running，系统版本与资源符合采购清单；
- SSH 密钥可登录，防火墙没有意外端口；
- Xray/3X-UI active，配置加载无致命错误；
- TCP 443 在云防火墙、系统防火墙、服务监听三层一致；
- 独立客户端通过 Reality 建立连接；
- 出口 IP 等于实例公网 IP；
- 出口和至少一个用户允许的 HTTP 目标通过；未测试的服务单独说明，不自动请求；
- Shadowrocket 业务组真实命中预期出口；
- 临时端口已清理；
- 本次涉及的客户端配置、密钥和数据库备份已本地保存并校验；
- 明确说明当前是否有订阅链接，不能把分享 URI 冒充订阅。

## 风险表述

- “独享 IP”只表示当前实例主要独自使用，不代表住宅 IP。
- “当前可访问”不代表长期不会被封锁或风控。
- 稳定节点无法消除账号因频繁切换国家、异常登录或违反服务条款产生的风险。
- 普通国际线路无法承诺深圳移动、联通、电信三个网络在所有晚高峰都一致。
- 面板或 Xray 升级可能引入协议回归；升级前备份，升级后执行完整验收。
- “未发现失陷迹象”只表示当前日志、登录来源、服务和端口没有异常证据，不等于完成取证级安全证明。
